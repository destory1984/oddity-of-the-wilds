# Oddity of the Wilds

브라우저에서 도는 작은 액션 RPG 데모다. 3D 블록 지형 위에 픽셀 그림 캐릭터 소라를 세우고,
화면 위아래를 흐리게 하는 틸트시프트와 빛번짐을 걸어 미니어처를 내려다보는 느낌을 냈다.

처음에는 Three.js 한 파일로 만들었고, 지금은 Godot 4.7로 옮긴 판을 웹으로 내보내 이 저장소에 둔다.
Godot 프로젝트 원본은 `godot/` 폴더에 있다. Godot 4.7에서 그 폴더를 열고 F5를 누르면 돈다.

## 실행

https://destory1984.github.io/oddity-of-the-wilds/ 를 연다. 엔진째로 받으므로 첫 로딩이 약 45MB다.

이 폴더에서 직접 열려면 로컬 서버를 띄운다.

```
python -m http.server 8765
```

그다음 `http://localhost:8765` 를 연다.

## 조작

| 키 | 하는 일 |
|---|---|
| WASD, 방향키 | 이동 (8방향) |
| Shift | 달리기 (기력 사용) |
| J, 왼쪽 클릭 | 공격 (3연속기) |
| K, 오른쪽 클릭 | 구르기 (기력 25). 적의 공격이 닿기 0.15초 전에 구르면 섬광 피하기: 2초 동안 적이 4배 느려짐 |
| L, 가운데 클릭 (누르고 있기) | 막기: 앞쪽 공격 피해 70% 줄임. 맞기 0.12초 전에 누르면 섬광 막기: 피해 0, 적 경직, 다음 베기는 2.5배 반격 |
| U I O, 1 2 3 | 스킬: 회오리(기세 30), 불씨탄(기세 15), 빛파동(기세 60) |
| 4 | 회복약 (체력 45 회복) |
| Space | 상자 열기 |
| Z X, 휠 | 확대·축소 |
| T R P | 시간 바꾸기 / 비 / 사진 모드 |
| M | 소리 켜고 끄기 |
| H | 조작법 창 열고 닫기 |

## 내용

- 현대 이스풍 전투로 키우는 중이다. 기세는 저절로 차지 않고 베기를 맞힐 때마다 5, 섬광 피하기 20, 섬광 막기 25씩 찬다. 4초 동안 못 때리면 줄어든다.
- 적을 맞히면 0.05 → 0.14초 동안 화면이 멈춰 손맛을 준다.
- 괴물은 때리기 전에 0.45초 동안 빨갛게 부풀고 머리 위에 "!"가 뜬다.

- 지도는 48x48칸이다. 북쪽에서 내려오는 강, 남쪽 호수와 섬, 북동쪽 언덕, 동쪽과 남서쪽 숲, 다리 3개가 있다.
- 다리 양끝 6곳과 풀밭 8곳에 가로등이 있고, 밤이 되면 밝아진다. 노을녘에는 비스듬한 햇살 줄기가 비친다.
- 레고 블록으로 쌓은 괴물 9마리가 돌아다니고, 잡으면 8초 뒤 다른 곳에 다시 나온다.
- 시작 지점 서쪽 오두막이 상점이다. 문 앞에서 Space를 누르면 열린다. 회복약 30, 기세 사탕(기세 +50) 20, 벼린 칼날(공격력 +3) 80, 튼튼한 갑옷(최대 체력 +15) 80 금화이고, 1 → 4 키나 단추로 산다.
- 지도 북쪽 끝에 보스 벽돌왕(체력 800)이 있다. 가까이 가면 깨어나 앞 휘두르기와 땅 찍기를 번갈아 쓴다. 체력이 절반 아래로 떨어지면 포효하며 고블린 둘을 부르고, 찍을 때마다 6칸까지 퍼지는 충격파를 낸다. 쓰러뜨리면 금화 300과 경험치 200을 준다.
- 경험치가 `레벨 x 25` 만큼 차면 레벨이 오르고 최대 체력 +12, 공격력 +3을 얻는다.
- 시간은 노을녘, 한낮, 해질녘, 밤 4단계다.
- 미니맵은 화면과 같은 방향으로 돌리고 납작하게 눕힌 둥근 양피지 지도다.
- 효과음은 코드에서 합성한다.

## 그림과 글꼴

- 주인공은 소라다. 걷기 그림(앞, 뒤, 옆, 대각선 8방향, 방향마다 4장)은 GPT 이미지 생성(Codex CLI)에 소라 설정화를 참고로 주고 그렸다.
  원본과 주문 문구는 `art/sora/` 에 있고, `art/cut.py` 가 분홍 배경을 지우고 칸을 다시 자른다.
- 제목 그림(`art/title/title.png`)은 GPT 이미지 생성(Codex CLI)에 우주한량 제목을 풍 참고로 주고 그렸다(크림 글자, 금색 두께, 남색 외곽선, 금 왕관, 부들). 주문 문구는 `art/title/gpt_prompt.txt` 에 있다. 권리 보유 자료다.
- 풀, 부들, 상자, 물 무늬는 코드에서 직접 찍는다.
- 글꼴은 Pretendard를 게임 데이터(`index.pck`) 안에 넣어 쓴다.
