# Oddity of the Wilds

브라우저에서 도는 작은 액션 RPG 데모다. 3D 블록 지형 위에 픽셀 그림 캐릭터를 세우고,
화면 위아래를 흐리게 하는 틸트시프트와 빛번짐을 걸어 미니어처를 내려다보는 느낌을 냈다.

파일 하나(`index.html`)에 Three.js 0.160.0을 CDN으로 불러 쓴다. 빌드 과정은 없다.

## 실행

`index.html` 을 브라우저로 열거나, 이 폴더에서 로컬 서버를 띄운다.

```
python -m http.server 8765
```

그다음 `http://localhost:8765` 를 연다. Three.js를 인터넷에서 받으므로 인터넷 연결이 필요하다.

## 조작

| 키 | 하는 일 |
|---|---|
| WASD, 방향키 | 이동 |
| Shift | 달리기 (기력 사용) |
| J, 왼쪽 클릭 | 공격 (3연속기) |
| K, 오른쪽 클릭 | 구르기 (기력 25 사용) |
| U I O, 1 2 3 | 스킬: 회오리(마력 10), 불씨탄(마력 8), 빛파동(마력 20) |
| 4 | 회복약 (체력 45 회복) |
| Space | 상자 열기 |
| Q E | 카메라 회전 |
| Z X, 휠 | 확대·축소 |
| T R P | 시간 바꾸기 / 비 / 사진 모드 |
| H | 조작법 창 열고 닫기 |

## 내용

- 지도는 48x48칸이다. 북쪽에서 내려오는 강, 남쪽 호수와 섬, 북동쪽 언덕, 동쪽과 남서쪽 숲, 다리 3개가 있다.
- 적 9마리가 돌아다니고, 잡으면 8초 뒤 다른 곳에 다시 나온다.
- 경험치가 `레벨 x 25` 만큼 차면 레벨이 오르고 최대 체력 +12, 공격력 +3을 얻는다.
- 시간은 노을녘, 한낮, 해질녘, 밤 4단계이고 오른쪽 위 하늘 그림의 해와 달 위치로 보여 준다.
