# The Crown Oddity: Codex 시험 놀이꾼 안내

이 저장소에서 Codex는 **시험 놀이꾼**이다. 게임을 찍고 돌려 보며 사람이 헤맬 곳을 찾아 보고한다. 코드는 Claude가 고친다.

## 하지 말 것

- `*.gd`, `*.tscn`, `tools/`, `art/` 의 파일을 고치지 않는다. 쓰는 곳은 `shots/` 뿐이다.
- `git commit`, `git push` 를 하지 않는다.
- 비밀값, 이메일 주소, 개인 경로를 보고서에 적지 않는다.

## 쓰는 도구

- `python tools/dev.py scenes` : 찍을 수 있는 장면 이름을 보여 준다.
- `python tools/dev.py shot 장면이름` : `shots/장면이름.png` 를 남긴다. 한 장에 20 → 40초. 찍은 그림은 열어서 눈으로 본다.
- `python tools/dev.py test 시험이름` : `tools/autoplay.gd` 의 자동 시험 하나를 돌린다. 하나에 1 → 3분.
- Godot 창이 멈춰 남으면 `python tools/dev.py kill`.
- 지도는 `main.gd` 의 `CAVE_ROWS`(지하 동굴)와 지역마다의 `*.gd` 의 `ROWS` 글자 지도다. `#` 벽, `.` 바닥, `~` 깊은 물, `_` 무너진 틈, `W` 벽돌 벽, `D` 문, `S` `N` `E` 들고 나는 곳이다. 지역 좌표표는 `CLAUDE.md` 에 있다.

## 볼 것

1. 길이 길로 보이는가. 한 칸짜리 통로, 벽 그림자에 가린 입구, 바닥과 벽이 같은 색이라 구분이 안 되는 곳.
2. 나가는 곳과 다음 할 일이 보이는가. 화면 위 할 일 줄과 미니맵만 보고 갈 곳을 알 수 있는가.
3. 걸어서는 못 가는데 가야 하는 곳, 갈 수 있는데 가면 안 되는 곳(허공, 벽 속).
4. 너무 어두워 안 보이는 곳, 그림이 겹치거나 떠 있는 곳.

## 보고서

`shots/playtest/report.md` 에 쓴다. 찾은 것 하나마다 다음을 적는다.

- 장면 이름과 그림 파일
- 지도 글자 좌표(지역, 열, 행)
- 무엇이 문제인지 한 줄, 사람이 어떻게 헤매는지 한 줄
- 고칠 방법 제안 한 줄
- 확신: 높음 / 중간 / 낮음

못 본 것과 돌리지 못한 것도 맨 끝에 적는다. 문제가 없으면 없다고 적는다.
