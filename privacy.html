Privacy Policy

The Crown Oddity · In effect from October 24, 2026

Personal data we collect

None. The game has no sign-up, no login, no ads, no purchases and no analytics. It does not ask for or read your name, email, phone number, location, contacts or device identifiers.

What stays on your device

  • Your game progress (story step, items, gold, map) and settings are stored only in the browser storage of your device.
  • This data is never sent to a server. The developer cannot see it.
  • Clearing the app's data or uninstalling the app deletes it.

Downloading the game files

When the game opens it downloads its files (about 45 MB) from GitHub Pages (destory1984.github.io). These requests carry no game data. GitHub runs the server and may keep basic logs such as IP addresses under the GitHub Privacy Statement.

Sharing

None. There is no data to sell or share.

Children

We do not collect personal data from children either.

Changes

If this policy changes, the new version will be posted on this page with a new date.
